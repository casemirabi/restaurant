# 🍝 Restaurante Gourmet

Site institucional responsivo para restaurante, desenvolvido em WordPress e exportado como site estático para deploy no GitHub Pages.

🔗 Acesse: https://casemirabi.github.io/restaurant/

---

## 🎯 Sobre o Projeto

Este projeto consiste em um site institucional completo com foco em apresentação do restaurante e conversão de clientes.

Principais funcionalidades:

* Página inicial com destaque visual e chamada para ação
* Cardápio organizado por categorias
* Seção "Sobre" com identidade do restaurante
* Página de contato com integração ao WhatsApp
* Layout responsivo (mobile-first)
* Navegação simples e intuitiva

---

## 🛠️ Tecnologias Utilizadas

* WordPress (CMS)
* Simply Static (exportação para HTML)
* HTML5
* CSS3
* JavaScript

## 🚀 Deploy

Este projeto é um site estático e pode ser hospedado facilmente em qualquer serviço:

### GitHub Pages

* Upload dos arquivos diretamente no repositório
* Configurar branch `main` como source

### Alternativas

* Netlify
* Vercel
* Hospedagem tradicional

O site possui links diretos para contato via WhatsApp.

* Busque por:

```id="o2p7rt"
https://wa.me/
```

* Substitua pelo número correto no formato:

```id="cgm3tb"
55 + DDD + número
```

## 🔧 Personalização

Para alterar conteúdos:

* Textos e páginas → editar HTML diretamente
* Imagens → pasta `wp-content/uploads`
* Estilos → arquivos CSS
